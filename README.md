# TrueTrack Tyres

A responsive static HTML/CSS/JavaScript website for a fictional tyre shop and wheel-alignment centre.

## Open locally

Serve the project folder with any static web server, then open `pages/index.html`.

## Structure

- `pages/` — thirteen public HTML pages
- `assets/css/` — shared mobile-first styles, dark-mode overrides and RTL overrides
- `assets/js/` — shared shell and interaction logic
- `assets/images/` — local, page-specific stock photography
- `documentation/` — project notes and image credits

The appointment form is a validated front-end interaction and does not send data until connected to a production booking system.
